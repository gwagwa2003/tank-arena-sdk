# 觀測：模型每一步看到的 118 個數字（`tank-arena-v3`）

`tank_arena.observation(state)` 產生的就是伺服器餵給模型的 118 維 `float32` 向量（與伺服器及參考引擎逐位相同）。
舊版 91 維模型（`tank-arena-v1`）上線時會自動截取前 91 維（`obs[:91]`），確保向後相容。

## 0–31：地形射線（32 個）

從車身正前方開始每隔 11.25°（π/16）量到最近未破壞牆體或場邊的距離，除以 320（帶雷達時 398），上限 1。

## 32–55：看得到的敵人（最多 4 個，每個 6 維）

| 偏移 | 內容 |
|---|---|
| +0 | 1（看得到敵人）；看不到整組為 0 |
| +1 | 距離 ÷ 自身視野（`340 + view_bonus`，帶雷達 +78） |
| +2, +3 | 相對敵人方向的 sin、cos |
| +4, +5 | v3 固定隱藏為 0.0（敵方速度不直接提供） |

## 56–75：附近敵方子彈（250 px 內最多 4 顆，每個 5 維）

`[1, d/250, sin(ang), cos(ang), closing_speed/14]`

## 76–90：自身狀態、毒圈、時間、技能

| 索引 | 內容 |
|---|---|
| 76 | 血量比例 `hp_frac`（0–1） |
| 77 | 裝填冷卻比例 `min(1, cooldown / reload)` |
| 78, 79 | 自身前進／右移實際速度 ÷ `(speed × 2)` |
| 80, 81 | 砲塔相對車身角度 sin、cos |
| 82, 83 | 安全區圓心相對角度 sin、cos |
| 84 | 到安全區圓心距離 ÷ 800 |
| 85 | `(zone_r - zone_dist) / 620`，夾在 -1～1 |
| 86 | 縮圈進度 `(620 - zone_r) / 530` |
| 87 | 步數進度 `t / 1200` |
| 88 | 存活敵人數 ÷ 4 |
| 89 | 技能冷卻剩餘 ÷ 模組冷卻 |
| 90 | 技能生效中 = 1.0 |

## 91–95：熱量、護盾、敵方車身朝向

| 索引 | 內容 |
|---|---|
| 91 | 槍管熱量 `heat / 100` |
| 92 | 過熱鎖定中 = 1.0 |
| 93 | 護盾剩餘比例 `shield / 7.8` |
| 94, 95 | 若有可見敵人：敵方車身相對我朝向的角度 sin、cos |

## 96–117：聲波、能量核心、草叢、破壞牆與姿態

| 索引 | 內容 |
|---|---|
| 96 | 聲波剩餘強度 `max(0, 1 - sound_age / 40)` |
| 97, 98 | 聲波方向 sin、cos（帶 ±0.26 rad 雜訊） |
| 99 | 聲波類型：開火 0.5、技能（隱身/雷達）1.0、無 0.0 |
| 100 | 能量核心狀態：未出現 0.0、預告 0.5、已生成 1.0 |

| 102 | 到核心距離 ÷ 800 |
| 103, 104 | 核心方向 sin、cos |
